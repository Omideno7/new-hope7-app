# New Hope 7 v1.9.2 — Offline-First Update

این Patch قابلیت آفلاین را روی نسخه تأییدشده v1.9.1 کامل‌تر می‌کند.

## فایل‌های قابل جایگزینی در GitHub
- `js/app.js`
- `service-worker.js`

## قابلیت‌ها
- Cache امن هسته اپ و همه فایل‌های داخلی ضروری
- دسترسی آفلاین به کتاب‌مقدس، برنامه‌های مطالعه، محتوای روزانه داخلی، شکرگزاری، نجات، معرفی کلیسا و مدرسه داخلی
- نگهداری آخرین نسخه دریافت‌شده Daily Content و School Content از Supabase برای قطع اینترنت
- دکمه آماده‌سازی محتوای اصلی آفلاین در Settings
- دانلود اختیاری هر موعظه یا فایل صوتی مدرسه برای استفاده بدون اینترنت
- دانلود اختیاری PDF درس برای آفلاین
- پشتیبانی Range Request برای پخش و جلو/عقب‌بردن فایل صوتی دانلودشده
- ادامه پخش و یادداشت‌ها همچنان در localStorage باقی می‌مانند
- پاک‌کردن فایل‌های رسانه‌ای دانلودشده از Settings

## نکات مهم
- فایل‌های صوتی و PDF حجیم خودکار دانلود نمی‌شوند؛ کاربر باید کنار هر فایل روی «دانلود برای آفلاین» بزند.
- ابتدا اپ باید یک بار با اینترنت باز شود و در Settings دکمه آماده‌سازی آفلاین زده شود.
- ورود اولیه، تأیید حساب، اعلان Push و دریافت محتوای کاملاً جدید همچنان به اینترنت نیاز دارند.
- تغییرات انجام‌شده در حالت آفلاین در صف محلی می‌مانند و پس از بازگشت اینترنت Sync می‌شوند.

SQL جدید لازم نیست.
