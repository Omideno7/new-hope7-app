# OmideNo7 Admin v1.6.4-admin5

این نسخه فقط پنل ادمین وب را تغییر می‌دهد و نیاز به آپلود نسخه جدید در Google Play ندارد.

## تغییرات

- دکمه «پیام داخل اپ» برای درخواست‌ها و پرسش‌ها اضافه شد.
- ادمین می‌تواند برای همان شخص پیام بنویسد تا در Inbox داخل اپ دریافت کند.
- پیام بر اساس `user_email` و اگر موجود باشد `device_id` در جدول `notification_inbox` ذخیره می‌شود.
- کاربر وقتی اپ را باز کند و صندوق ورودی/Inbox را تازه کند، پیام را می‌بیند.

## فایل‌های پچ

- `admin.html`
- `service-worker.js`
- `supabase_admin5_inbox_messages.sql`

## نکته

این پیام داخل Inbox اپ ذخیره می‌شود. Push notification فوری روی صفحه گوشی فقط با مرحله سروری/OneSignal قابل اضافه شدن است.
