# New Hope 7 v1.8.0 Hotfix 5

این نسخه دو مشکل مدیریت مدرسه را اصلاح می‌کند:

1. هر هشت کلاس بنیادی موجود در فایل داخلی اپ همیشه در پنل ادمین نمایش داده می‌شوند. اگر فقط کلاس ۱ در Supabase باشد، کلاس‌های ۲ تا ۷ و کلاس ۴B از پنل حذف نمی‌شوند. با ویرایش و ذخیره هر کلاس، همان کلاس به Supabase منتقل یا به‌روزرسانی می‌شود.
2. مدیریت مستقل دوره‌ها/مجموعه‌های آموزشی اضافه شده است. می‌توان دوره‌هایی مانند Foundation School، تعلیم فرشتگان، خدمت و اقتدار و شفا ساخت و هر کلاس را به دوره مربوط متصل کرد.

## نصب

1. ابتدا فایل `supabase_v1_8_0_hotfix5_school_courses.sql` را در SQL Editor اجرا کنید.
2. سپس `admin.html`، `js/app.js` و `service-worker.js` را در GitHub جایگزین کنید.
3. بعد از Deploy، پنل ادمین را با Ctrl+Shift+R تازه‌سازی کنید.
4. در مدیریت مدرسه روی «همگام‌سازی هر ۸ کلاس بنیادی» بزنید.

این نسخه محتوای فعلی مدرسه را حذف نمی‌کند و دوره بنیادی را به‌عنوان دوره پیش‌فرض حفظ می‌کند.
