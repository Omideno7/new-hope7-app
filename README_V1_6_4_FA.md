# OmideNo7 v1.6.4 - Meeting Settings Live Sync Fix

این نسخه مشکل نمایش مقدار قدیمی لینک/کد جلسه برای کاربران را اصلاح می‌کند.

## لازم است
1. فایل SQL `supabase_v1_6_4_meeting_settings_rpc_fix.sql` را در Supabase اجرا کنید.
2. فایل‌های وب‌اپ را روی GitHub Pages آپلود کنید.
3. کاربران از Settings گزینه Refresh app data را بزنند.

## تغییر اصلی
- اپ کاربران تأییدشده، لینک جلسه و کد امنیتی را از RPC امن `nh7_get_meeting_settings` می‌خواند.
- اگر ادمین لینک یا کد را عوض کند، کاربران تأییدشده مقدار جدید را می‌بینند.
- شماره تماس و کد دسترسی همچنان برای کاربران نمایش داده نمی‌شود.
