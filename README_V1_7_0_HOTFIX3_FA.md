# New Hope 7 v1.7.0 Hotfix 3 — Professional Sermon Player

این Patch روی Hotfix 2 ساخته شده و قابلیت‌های سالم قبلی را حفظ می‌کند.

## تغییرات
- پخش‌کننده سراسری و پایدار موعظه که با جابه‌جایی بین صفحات قطع نمی‌شود.
- ذخیره خودکار آخرین موقعیت پخش برای هر موعظه.
- ادامه شنیدن، شروع مجدد، ۱۵ ثانیه عقب و ۳۰ ثانیه جلو.
- سرعت‌های 0.75x، 1x، 1.25x، 1.5x و 2x.
- نمایش زمان فعلی، زمان کل و درصد شنیده‌شده.
- پشتیبانی Media Session برای کنترل از صفحه قفل/اعلان سیستم در مرورگرهای سازگار.
- یادداشت جداگانه برای هر موعظه با ذخیره محلی و Cloud Queue موجود.
- تشخیص خودکار عنوان از نام فایل MP3 و مدت فایل هنگام انتخاب در پنل ادمین.
- افزایش نسخه Cache سرویس‌ورکر برای دریافت Patch جدید.

## نکته
برای این Patch تغییر SQL جدیدی لازم نیست. جدول‌های sermons و sermon_categories همان ساختار v1.7.0 را استفاده می‌کنند.
