# OmideNo7 v1.5.0 — Production Fixes

این نسخه برای بعد از تکمیل Closed Testing آماده شده است.

## اصلاحات مهم
- اصلاح قوی‌تر تأیید مدرسه و جلسات با خواندن وضعیت تأیید از Supabase بر اساس ایمیل و دستگاه.
- فرم ثبت‌نام: فیلد تاریخ تولد با عنوان واضح «تاریخ تولد» و راهنمای روز/ماه/سال.
- صندوق ورودی: پیام‌های حذف‌شده دوباره با پیام‌های زمان‌بندی‌شده ساخته نمی‌شوند.
- Daily Word / Faith / Juice: دکمه تکمیل روز وضعیت ذخیره‌شده را نشان می‌دهد.
- Gratitude: امکان مشاهده روزهای قبلی، انتخاب روزهای بازشده، ذخیره یادداشت همان روز، و لغو تکمیل روز.
- آیات ذخیره‌شده: امکان باز کردن فقط همان آیه، باز کردن کل فصل، و حذف آیه ذخیره‌شده.
- Bible Reader: هایلایت و یادداشت هر آیه به‌صورت پایدار روی دستگاه ذخیره می‌شود؛ اشتراک‌گذاری آیه اضافه شد.
- Android Back button / Browser back: با تاریخچه مسیرهای اپ هماهنگ شد.
- نام نمایشی داخل فایل‌ها به OmideNo7 Church به‌روزرسانی شد؛ package name اندروید تغییر نمی‌کند.

## روش آپلود
محتوای داخل ZIP را در ریشه GitHub Pages جایگزین کن. خود فایل ZIP را آپلود نکن.
بعد از آپلود، از Settings داخل اپ گزینه Refresh app data را بزنید.
