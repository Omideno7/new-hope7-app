# New Hope 7 v1.7.0 Hotfix 6

این نسخه مشکل ورود حساب‌های قدیمی و تأییدشده مدرسه روی دستگاه جدید را اصلاح می‌کند.

- ابتدا ورود عادی Supabase Auth انجام می‌شود.
- اگر حساب Auth قدیمی وجود نداشته باشد، سیستم ثبت‌نام تأییدشده مدرسه را با همان ایمیل بررسی می‌کند.
- فقط در صورت تأیید قبلی ادمین، حساب قدیمی به حساب چنددستگاهی تبدیل می‌شود.
- ثبت‌نام یا تأیید مجدد مدرسه لازم نیست.
- هیچ SQL جدیدی لازم نیست؛ SQL Hotfix 5 باید قبلاً اجرا شده باشد.
