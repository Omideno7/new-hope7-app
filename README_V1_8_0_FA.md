# New Hope 7 v1.8.0 — مدیریت داینامیک مدرسه، مرحله اول

این Patch ساختار و ظاهر فعلی مدرسه را تغییر نمی‌دهد. اپ ابتدا کلاس‌های فعال را از Supabase می‌خواند و اگر دیتابیس یا اینترنت در دسترس نبود، فایل فعلی `school_content.json` را نمایش می‌دهد.

## امکانات
- تب «مدیریت مدرسه» در پنل ادمین
- واردکردن امن کلاس‌های فعلی اپ به Supabase با یک دکمه
- افزودن، ویرایش، فعال/غیرفعال و حذف درس
- تغییر ترتیب درس‌ها
- ویرایش فارسی، انگلیسی و کرواتی
- ویرایش خلاصه، تکلیف، متن کامل و آیات کلیدی
- ثبت URL صوت Supabase، ویدئو و PDF

## نصب
1. فایل `supabase_v1_8_0_dynamic_school.sql` را در Supabase SQL Editor اجرا کنید.
2. فایل‌های `admin.html` و `js/app.js` را در GitHub جایگزین کنید.
3. بعد از Deploy، در پنل ادمین تب «مدیریت مدرسه» را باز کنید.
4. فقط یک بار «واردکردن کلاس‌های فعلی اپ» را بزنید.

این مرحله آزمون‌ها و گزارش پیشرفت کاربران را تغییر نمی‌دهد؛ آن‌ها در مرحله دوم مدیریت مدرسه اضافه می‌شوند.
