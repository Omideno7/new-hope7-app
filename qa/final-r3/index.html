موارد جدید این دور

  • هایلایت اپوکریفا: رنگ انتخاب‌شده باید بلافاصله روی همان آیه دیده شود و پس از بازگشت به باب باقی بماند.
  • ستارهٔ ذخیره: بار اول آیه ذخیره می‌شود و بار دوم همان ستاره، آیه را از ذخیره خارج می‌کند؛ نسخهٔ حساب آنلاین نیز همگام می‌شود.
  • حذف حساب: بیشتر ← حساب کاربری ← حذف کامل حساب. حذف فقط پس از واردکردن رمز فعلی، ایمیل حساب و کلمه DELETE انجام می‌شود.
  • حذف داده‌ها: ثبت‌نام، مدرسه، تکالیف، امتحان‌ها، آیات و یادداشت‌ها، پلن‌ها، پیام‌ها و دسترسی‌های شخصی همراه Auth حذف می‌شوند.
  • حفاظت: حساب مالک یا ادمین از داخل اپ قابل حذف نیست.
برای تست حذف حساب فقط از یک حساب تستی استفاده کن. این دکمه واقعاً Backend را اجرا می‌کند و حذف دائمی است. برای حساب اصلی یا حساب ادمین آن را امتحان نکن.

یادآوری درباره Merge

در مرحلهٔ انتشار، کل برنچ آزمایشی به‌صورت کور جایگزین main نمی‌شود. تغییرات تأییدشده روی یک برنچ تازه که از آخرین main ساخته می‌شود منتقل و تعارض‌ها دستی حل می‌شوند؛ بنابراین امکانات فعلی main حفظ می‌شوند و اصلاحات جدید به آن‌ها اضافه می‌گردند.
