اصلاحات اصلی این دور

  • موعظات: Bucket `church-audio` خصوصی است؛ بنابراین هر موعظه اکنون پیش از پخش یا دانلود Signed URL شش‌ساعته دریافت می‌کند.
  • مدرسه: صوت درس نیز از همان Edge Function امن و storage path واقعی دریافت می‌شود؛ Handlerهای قدیمی متداخل از QA حذف شده‌اند.
  • Safari: اگر مرورگر پس از دریافت Async لینک اجازه autoplay ندهد، کنترل صوتی Native روی همان کارت نمایش داده می‌شود تا فایل واقعاً قابل پخش باشد.
  • دانلود: درصد دانلود نمایش داده می‌شود؛ بعد از پایان، کلید سبز «دانلود شد ✓» می‌شود و فایل با شناسهٔ ثابت برای آفلاین ذخیره می‌گردد.
  • Offline: محتوای اصلی و فایل‌های دانلودشده Cache مستقل دارند؛ Auth/RPC/Edge/Signed URLs عمداً Cache نمی‌شوند.
  • Admin: Backend جدید v395 فهرست را برای Owner یا ادمین فعال دارای مجوز `registrations.view` برمی‌گرداند. بررسی مستقیم: ۳۱ کاربر تأییدشده و ۷۱ حساب.
  • منابع خادمین: اگر فهرست کاربران دیده شود ولی Checkbox منبع خالی باشد، علت این است که هنوز هیچ آیتم فعال با Audience = ministers منتشر نشده است.
  • منو/Settings: Gratitude تکراری از More حذف می‌شود، Video در Settings حذف می‌شود و Settings بازخورد قابل مشاهده دارد.
  • Saved Apocrypha: مسیر مستقیم کتاب/باب/آیه و علامت سبز روی متن آیه حفظ شده است.
ترتیب تست پیشنهادی: ابتدا با حساب کامل و تأییدشده در همین دامنه QA وارد شو. یک MP3 و یک M4A موعظه را پخش و دانلود کن؛ بعد یک صوت مدرسه را تست کن. سپس Offline، Admin Tools، Settings و Saved Apocrypha را بررسی کن.
