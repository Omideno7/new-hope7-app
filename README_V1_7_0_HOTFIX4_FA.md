# New Hope 7 v1.7.0 Hotfix 4

این Patch روی نسخه رسمی New Hope 7 منتشرشده در Google Play ساخته شده است.

## تغییرات
- نمایش مدت موعظه به صورت دقیقه و ثانیه (`mm:ss` و برای فایل‌های طولانی `h:mm:ss`)
- ذخیره مدت فایل جدید در پنل ادمین با دقت اعشاری برای حفظ ثانیه‌ها
- پخش‌کننده کوچک داخل همان کارت موعظه
- پخش، توقف، ۱۵ ثانیه عقب، ۳۰ ثانیه جلو، نوار زمان و سرعت پخش در همان فهرست
- حفظ ادامه پخش هنگام جابه‌جایی در اپ
- پنجره جدا و مرتب برای یادداشت موعظه
- حذف دکمه و وضعیت «مهمان» از صفحه مدرسه
- دو انتخاب روشن: «ورود به مدرسه» و «ثبت‌نام جدید»
- ورود با ایمیل و رمز حساب موجود روی دستگاه دیگر
- بازیابی وضعیت تأیید مدرسه از Supabase بر اساس حساب و ایمیل
- بازگشت به صفحه ورود مدرسه پس از خروج از داخل مدرسه

## پایگاه داده
SQL جدید لازم نیست. همان ساختار و SQL نسخه v1.7.0 حفظ شده است.

## فایل صوتی
هیچ فایل صوتی محلی داخل این ZIP قرار ندارد. فایل‌ها از Supabase Storage خوانده می‌شوند.
