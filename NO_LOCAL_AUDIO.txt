New Hope 7 — No Local Audio Package

This project ZIP intentionally contains no sermon, prayer, teaching, or school audio media files.
All audio content must be managed from the Admin Panel and loaded from Supabase Storage / the configured remote URL.
Do not add MP3, M4A, WAV, AAC, OGG, or FLAC files to the GitHub deployment package.

Code, audio player features, metadata detection, notes, playback speed, and resume playback remain included.
