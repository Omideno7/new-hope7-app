# OmideNo7 Admin v1.6.4-admin4

این نسخه فقط پنل ادمین وب را بهتر می‌کند و نیاز به ارسال دوباره اپ به Google Play ندارد.

## تغییرات
- وضعیت درخواست‌ها بهتر نمایش داده می‌شود: اگر یک ایمیل قبلاً تأیید شده باشد، تکراری‌های همان ایمیل/type در پنل به صورت تأیید شده نمایش داده می‌شوند.
- دکمه همگام‌سازی وضعیت‌ها اضافه شد.
- دکمه حذف تکراری‌ها اضافه شد.
- دکمه حذف تکی درخواست‌ها از طریق RPC امن Supabase کار می‌کند.

## لازم
فایل `supabase_admin4_registration_cleanup.sql` را یک بار در Supabase SQL Editor اجرا کنید.
