# OmideNo7 v1.6.0 — Tester Fixes

این نسخه بر اساس گزارش تسترها آماده شده است.

## اصلاحات اصلی
- حذف پایدار پیام‌های Inbox و جلوگیری از برگشت پیام‌های حذف‌شده.
- نمایش روزهای قبلی در کلام روزانه، اعلان ایمان و آبمیوه روزانه.
- اصلاح مسیر دوره شکرگزاری در منوی بیشتر.
- ترجمه بهتر نام کتاب‌های کتاب‌مقدس در آدرس آیات، از جمله Psalm/Psalms به مزامیر.
- آیات ذخیره‌شده: باز کردن همان آیه، باز کردن کل فصل، حذف آیه.
- ذخیره پایدار دکمه کامل شد.
- مدرسه: دکمه ورود به مدرسه و تازه‌سازی وضعیت تأیید.
- جلسات: حذف منطق مهمان و افزودن دکمه ورود به جلسه/تازه‌سازی تأیید.
- فرم مدرسه: عنوان واضح تاریخ تولد.
- کتاب‌مقدس: هایلایت، یادداشت و اشتراک‌گذاری آیه.
- حساب کاربری: گزینه فراموشی رمز عبور.
- پرسش و پاسخ: جلوگیری از سؤال تکراری، پیام انتظار دو هفته‌ای، ذخیره نام/ایمیل برای ادمین و نمایش عمومی گمنام.
