# OmideNo7 v1.6.3

اصلاحات این نسخه:

- متن‌های کلام روزانه کمتر تکراری شدند و مطالعات بیشتر برای هر روز آیات متفاوت‌تری دارد.
- اعلان ایمان کامل‌تر شد و فقط خط اول تغییر نمی‌کند.
- جلسات کلیسا فقط لینک جلسه و کد امنیتی را نمایش می‌دهد.
- شماره تماس و کد دسترسی از نمایش کاربران و فرم اصلی ادمین حذف شد.
- ادمین می‌تواند لینک جلسه و کد امنیتی را از پنل ادمین تغییر دهد.
- کاربر تأییدشده مدرسه برای جلسه ثبت‌نام جداگانه لازم ندارد.
- نسخه برنامه به OmideNo7 v1.6.3 تغییر کرد.

قبل از استفاده از تنظیمات جلسه، فایل SQL نسخه v1.6.3 را در Supabase اجرا کنید.
