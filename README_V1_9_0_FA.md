# New Hope 7 v1.9.0 Internal — Major School & Admin Milestone

این نسخه یک مرحله بزرگ داخلی است و هنوز نسخه نهایی Google Play نیست.

## اضافه‌شده
- داشبورد مدیریتی و آمار اصلی
- خروجی پشتیبان کامل JSON
- توضیح واضح Course Code و ساخت خودکار آن
- مدیریت آزمون هر درس
- سؤال‌های چندگزینه‌ای سه‌زبانه
- نمره قبولی و تعداد تلاش
- ثبت تکمیل درس و پیشرفت کاربر
- نمایش نتیجه و پیشرفت در پنل ادمین
- ریست پیشرفت از پنل
- حفظ دوره‌ها، کلاس‌های بنیادی، موعظه‌ها، محتوای روزانه و Login فعلی

## نصب
1. ابتدا `supabase_v1_9_0_school_exams_progress.sql` را در SQL Editor اجرا کنید.
2. سپس `admin.html`، `js/app.js` و `service-worker.js` را جایگزین کنید.
3. Deploy را صبر کنید و Cache را تازه‌سازی کنید.

## مهم
- این نسخه باید قبل از انتشار Google Play روی یک حساب آزمایشی تست شود.
- سیاست‌های RLS در SQL برای سازگاری با ساختار فعلی ساده نگه داشته شده‌اند؛ در مرحله امنیت نهایی باید Owner role سخت‌گیرانه شود.
