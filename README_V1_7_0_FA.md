# New Hope 7 v1.7.0 — Dynamic Church Platform

مبنای این نسخه، نسخه پایدار منتشرشده `1.6.4` است. قابلیت‌های سالم قبلی حذف نشده‌اند و داده‌های قدیمی Local Storage و ثبت‌نام‌های قبلی حفظ می‌شوند.

## تغییرات اصلی

### حساب کاربری
- خروج واقعی و پایدار در هر سه زبان
- جلوگیری از ورود دوباره پس از تغییر زبان
- صفحه ورود ایمیل/رمز بعد از Logout
- نمایش/پنهان کردن رمز
- بازیابی رمز با Supabase Auth
- ساخت حساب هنگام ثبت‌نام جدید
- مسیر بازیابی دسترسی کاربران قدیمی حفظ شده است

### Inbox
- ثبت وضعیت خوانده‌شدن در Supabase
- ثبت حذف شخصی در `notification_inbox_receipts`
- پیام حذف‌شده پس از باز کردن مجدد اپ برنمی‌گردد
- پیام‌های عمومی برای سایر کاربران حذف نمی‌شوند

### موعظه‌های داینامیک
- دسته‌بندی‌های قابل افزودن/حذف از پنل ادمین
- عنوان و توضیح فارسی، انگلیسی و کرواتی
- آپلود MP3 و تصویر کاور از پنل
- لینک YouTube
- مدت، ترتیب نمایش، انتشار/عدم انتشار
- اپ موعظه‌ها را مستقیم از Supabase می‌خواند
- در صورت در دسترس نبودن Supabase، فهرست صوتی قدیمی به‌عنوان fallback باقی می‌ماند

### اعلان‌ها
- تنظیم زمان و متن سه‌زبانه از پنل ادمین
- زمان محلی یا `Europe/Zagreb`
- اعلان‌های بومی Android از طریق Capacitor Local Notifications
- رفع پیام اشتباه «مرورگر پشتیبانی نمی‌کند» در اپ Android جدید
- بازسازی خودکار برنامه اعلان‌های Android هنگام شروع اپ
- ارسال فوری سه‌زبانه به Inbox از پنل ادمین

### پنل ادمین
- تب موعظه‌ها
- مدیریت دسته‌بندی‌ها
- آپلود MP3/کاور
- تب مدیریت اعلان‌ها
- JWT refresh برای جلوگیری از خطای `PGRST303 JWT expired`
- قابلیت‌های درخواست‌ها، پرسش و پاسخ، جلسات و پیام داخل اپ حفظ شده‌اند

## ترتیب نصب

1. از پروژه Supabase بکاپ بگیرید.
2. فایل `supabase_v1_7_0_dynamic_platform.sql` را در SQL Editor اجرا کنید.
3. فایل‌های این ZIP را در GitHub جایگزین کنید.
4. نسخه وب را با `?v=170` تست کنید.
5. روی یک گوشی Android آزمایشی نسخه جدید را نصب و تست کنید.
6. سپس AAB با `versionCode 170` و `versionName 1.7.0` بسازید.

- آپلود فایل MP3 و کاور
