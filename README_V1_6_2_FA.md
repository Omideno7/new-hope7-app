# OmideNo7 v1.6.2 Daily Content + Account Fix

این نسخه برای اصلاح محتوای روزانه و دسترسی حساب آماده شده است.

## اصلاحات
- کلام روزانه: پیام، دعا و مطالعات بیشتر برای همه روزها بازسازی و از حالت تکراری خارج شد.
- اعلان ایمان: متن کامل اعلان‌ها برای هر روز بازسازی شد؛ فقط خط اول تغییر نمی‌کند، بلکه کل متن با موضوع روز هماهنگ است.
- آبمیوه روزانه: قدم عملی و مطالعات بیشتر چرخشی/متفاوت شد.
- مطالعات بیشتر: آیه‌های دوم و سوم دیگر ثابت نیستند و برای روزهای مختلف تغییر می‌کنند.
- حساب کاربری: ورود/بازیابی دسترسی با ایمیل، خروج از حساب روی همین دستگاه، و بازیابی رمز عبور در بخش Account اضافه/تقویت شد.
- مدرسه: در حالت تأییدشده دکمه مدیریت حساب و خروج از حساب اضافه شد.
- نسخه تنظیمات: OmideNo7 v1.6.2
