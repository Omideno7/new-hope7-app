# New Hope 7 v1.8.0 Hotfix 3

این بسته دو اصلاح را با هم نگه می‌دارد:

1. حفظ و بازگردانی کامل کلاس‌های فعلی مدرسه و امکان افزودن دوره‌های جدید.
2. نمایش فوری آخرین ویرایش‌های Daily Word، Faith Proclamation و Daily Juice از Supabase.

محتوای روزانه دیگر از Cache قدیمی خوانده نمی‌شود. اپ در هر بار بازکردن روز، تازه‌ترین رکورد فعال همان روز را از Supabase دریافت می‌کند و فقط در صورت قطع اینترنت یا خطا از فایل داخلی استفاده می‌کند.

SQL جدید لازم نیست. SQLهای v1.7.1 و مدرسه باید قبلاً اجرا شده باشند.
