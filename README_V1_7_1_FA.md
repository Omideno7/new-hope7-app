# New Hope 7 v1.7.1 — نسخه داخلی توسعه

این نسخه برای انتشار مستقیم در Google Play نیست و باید ابتدا آزمایش شود.

## قبل از آپلود فایل‌ها
1. فایل `supabase_v1_7_1_notification_daily_content.sql` را در Supabase SQL Editor اجرا کنید.
2. سپس همه فایل‌های پروژه را در GitHub جایگزین کنید.
3. بعد از Deploy، Cache را تازه‌سازی کنید.

## تغییرات
- شناسه ثابت روزانه برای اعلان‌ها و جلوگیری از تکرار بین چند دستگاه
- حذف پایدار و گروهی اعلان‌های تکراری
- عدم ذخیره دوباره اعلان‌های زمان‌بندی محلی در Cloud
- مدیریت داینامیک Daily Word، Faith Proclamation و Daily Juice از پنل ادمین
- حفظ فایل‌های JSON فعلی به‌عنوان fallback آفلاین
- ابزار پاک‌سازی اعلان‌های تکراری قدیمی در پنل ادمین
