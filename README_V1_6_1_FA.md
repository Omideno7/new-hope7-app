# OmideNo7 v1.6.1 — Notifications + Daily Word + Meeting Access Fix

این نسخه از روی v1.6.0 ساخته شده و این موارد را اصلاح می‌کند:

- فعال‌سازی اعلان‌ها پایدارتر شد و مسیر Service Worker برای GitHub Pages به صورت خودکار تنظیم می‌شود.
- متن کلام روزانه با مجموعه ۳۶۵ روزه‌ی کامل و عمیق‌تر جایگزین شد؛ هر روز پیام، دعا و مطالعه بیشتر خودش را دارد.
- نام کتاب‌های کتاب‌مقدس در آدرس آیات برای فارسی و کرواتی با نقشه کامل‌تر ترجمه می‌شود؛ مثل John → یوحنا و Psalm/Psalms → مزامیر.
- دسترسی جلسات کلیسا از تأیید مدرسه هم پذیرفته می‌شود؛ یعنی کسی که مدرسه‌اش تأیید شده دیگر ثبت‌نام جداگانه جلسه لازم ندارد.
- ورود مهمان در جلسات حذف/غیرفعال شد؛ لینک و کد جلسه فقط برای کاربر تأییدشده نمایش داده می‌شود.
- اگر تنظیمات جلسه در Supabase موجود نباشد، اطلاعات FreeConferenceCall امیدنو۷ به صورت امن فقط بعد از تأیید نمایش داده می‌شود.

آپلود: محتوای داخل ZIP را در ریشه GitHub Pages جایگزین کنید؛ خود ZIP را آپلود نکنید.
