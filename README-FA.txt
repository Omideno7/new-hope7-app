New Hope 7 v2.3.1 — اصلاح انتخاب گروهی آیات

فقط چهار فایل تغییر کرده است:
1) index.html
2) service-worker.js
3) css/v2.3.0-access-bible.css
4) js/nh7-app-enhancements-v230.js

همه فایل‌ها را با همین مسیرها در GitHub جایگزین کنید.
هیچ SQL و هیچ تغییر Supabase برای این اصلاح لازم نیست.

نتیجه:
- دایره‌های روی متن آیات کاملاً حذف می‌شوند.
- فاصله اضافه سمت آیات حذف می‌شود و متن خوانا می‌ماند.
- با لمس مستقیم خود آیه، آن آیه انتخاب می‌شود.
- با لمس آیات بعدی، انتخاب گروهی ادامه پیدا می‌کند.
- با لمس دوباره آیه انتخاب‌شده، از انتخاب خارج می‌شود.
- آیات انتخاب‌شده با خط آبی زیر متن مشخص می‌شوند.
- ابزارهای ذخیره، هایلایت، یادداشت، کپی و اشتراک گروهی باقی می‌مانند.
- دکمه‌ها و فیلدهای داخل ابزار آیه باعث انتخاب یا لغو ناخواسته آیه نمی‌شوند.

بعد از آپلود، GitHub Pages را باز کنید و یک بار صفحه را کامل ببندید و دوباره باز کنید تا Service Worker نسخه 2.3.1 فعال شود.
